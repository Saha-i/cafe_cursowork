# Меню кафе (Cafe Menu)

Веб-приложение для автоматизации учета и ведения меню в небольших кафе или ресторанах. Проект разработан в рамках курсовой работы.

## 📋 Функционал
*   **Аутентификация:** Регистрация и вход пользователей (пароли хешируются с помощью PBKDF2).
*   **Персонализация:** Каждый пользователь видит и управляет только своими блюдами.
*   **Управление меню:** Добавление, редактирование и удаление блюд.
*   **Категории:** Поддержка предустановленных категорий (Горячее, Салаты, Десерты, Напитки).
*   **Фильтрация:** Быстрый поиск и фильтрация блюд по категориям.
*   **Валидация:** Проверка вводимых данных (цены, веса, названия) на стороне сервера.

## 🛠️ Стек технологий
*   **Язык:** Java 21
*   **Фреймворк:** Spring Boot 4.1 (Spring MVC, Spring Data JPA)
*   **База данных:** H2 (встраиваемая, файловый режим)
*   **Шаблонизатор:** Thymeleaf
*   **Сборка:** Maven
*   **Фронтенд:** HTML5, CSS3 (адаптивный дизайн)

## 🚀 Как запустить проект локально
1. Убедитесь, что у вас установлена **Java 21** и **Maven**.
2. Клонируйте репозиторий:
   `git clone https://github.com/ваш-логин/название-репозитория.git`
3. Перейдите в папку с проектом и запустите приложение:
   `./mvnw spring-boot:run` (или через ваш IDE).
4. Откройте в браузере: `http://localhost:8080`
